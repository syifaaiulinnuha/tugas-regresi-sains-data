## Ringkasan Hasil
- Bagian A: Model Linear Regression dilatih untuk meramalkan variabel target kontinu (`tip`) berdasarkan fitur-fitur restoran. Performa model dievaluasi menggunakan metrik MAE, RMSE, dan R-squared.
- Bagian B: Model Logistic Regression dilatih untuk mengklasifikasikan status keselamatan penumpang (`survived`) pada dataset Titanic. Performa model dievaluasi menggunakan Accuracy, Precision, Recall, F1-Score, dan kurva ROC-AUC.
